### HyperFlow 특징
- 개발부터 서비스 런칭까지 하나의 플랫폼에서
- 구성은 자유롭게, 결과 확인은 실시간으로
- 드래그 앤 드롭으로 간편한 워크플로우 설계
- 고급노드 하나로 복잡한 로직을 간단하게
- 노코드로 설계하고 필요할 땐 풀코드로 맞춤 설정

| 특징 | 설명 |
|-----|-----|
| 1️⃣ 개발부터 서비스 런칭까지 하나의 플랫폼에서     | 아이디어 구상부터 개발, 테스트, 실제 서비스 배포까지, 모든 과정을 한 플랫폼에서 빠르고 유연하게 진행할 수 있습니다. |
| 2️⃣ 구성은 자유롭게, 결과 확인은 실시간으로       | LLM모델, 데이터, 프롬프트, 임베딩, 양자화 방식까지 핵심 요소를 자유롭게 조정하며 반복 테스트 할 수 있습니다. 실행 결과는 클릭 한 번으로 바로 확인 할 수 있어요. |
| 3️⃣ 드래그 앤 드롭으로 간편한 워크플로우 설계     | 직관적인 UI로 노드를 연결해 원하는 흐름을 설계하고, AI 서비스를 쉽고 빠르게 완성할 수 있습니다. |
| 4️⃣ 고급노드 하나로 복잡한 로직을 간단하게        | 반복 작업부터 조건 처리, 메모리 관리까지 손쉽게 구성하며 정밀한 AI 설계까지 가능합니다. |
| 5️⃣ 노코드로 설계하고 필요할 땐 풀코드로 맞춤 설정 | 노코드로 시작하고, 필요할 땐 코드로 직접 기능을 확장하세요. 파이썬 노드를 활용하면 더욱 정교한 워크플로우 설계가 가능합니다. |
| 6️⃣ 여러 기능을 하나로, 다기능 슈퍼노드          | 하나의 노드에 여러 기능이 내장되어있어, 설정만으로 OCR, 파싱, PDF-MD 변환 등 다양한 작업을 손쉽게 처리할 수 있습니다. |
| 7️⃣ | Built-in 템플릿으로 간편하게 구축하는 RAG 챗봇 | 미리 준비된 템플릿을 활용해 복잡한 설정 없이 지식베이스를 구축하고, 챗봇과 연결하면 준비 |
| 8️⃣ API Key 관리와 프로젝트 권한 설정 | 관리자 권한으로 API Key를 등록하고, 각 프로젝트별로 권한을 배분할 수 있습니다. 통합 관리 방식으로 보안은 높이고, 운영은 더 간편해집니다. |
| 9️⃣ 텍스트를 넘어서는 멀티모달 AI      | 텍스트 뿐 아니라 이미지, 오디오, PDF 등 다양한 데이터를 처리해 활용 범위를 확장합니다. 로고와 챗봇 이름은 물론, 색상-형태-글꼴까지 자유롭게 설정할 수 있습니다. 필요한 경우 CSS에서 원하는 스타일로 완전한 커스터마이징이 가능합니다. |
| 🔟 로고부터 스타일까지 커스텀 디자인으로. | 로고와 챗봇 이름은 물론, 색상-형태-글꼴까지 자유롭게 설정할 수 있습니다. 필요한 경우 CSS에서 원하는 스타일로 완전한 커스터마이징이 가능합니다. |
| #️⃣ 배포된 서비스를 한눈에 관리           | 배포한 모든 서비스를 실시간으로 하나의 대시보드에서 확인하고 제어하며, 업데이트 할 수 있습니다. |
