☑ **양자컴퓨터**
- 양자역학의 원리를 활용해 정보를 처리하는 컴퓨터
- 기존 컴퓨터는 정보를 비트(bit) 단위로 처리하는데, 이 비트는 항상 0 또는 1 중 하나의 값을 가진다.
- 반면 양자컴퓨터는 **큐비트(qubit)** 라는 단위를 사용
  - 0과 1을 동시에 표현할 수 있어 → 이를 **양자 중첩(Superposition)** 이라고 함
  - 여러 큐비트가 서로 연결되어 상태를 공유할 수 있어 → 이건 **양자 얽힘(Entanglement)** 이라고 함

- 기존 컴퓨터보다 뛰어난 점  
    | 항목 | 기존 컴퓨터 | 양자컴퓨터 | 
    |-----|-----------|-----------|
    | 정보 단위 | 비트 (0 또는 1) | 큐비트 (0과 1 동시에 가능) | 
    | 계산 방식 | 순차적 | 병렬적 | 
    | 처리 속도 | 제한적 | 폭발적으로 빠름 | 
    | 암호 해독 | 수백 년~수천 년 | 몇 초~몇 분 | 
    | 복잡한 문제 해결 | 어려움 | 가능성 있음 | 

☑  **OCR(Optical Character Recognition) : 광학 문자 인식**
- 이미지나 스캔된 문서 속의 텍스트를 컴퓨터가 읽을 수 있는 문자 데이터로 변환하는 기술
- 예를 들어, 종이 문서를 스캔하면 이미지 파일이 만들어짐. <br/> ⇒ 그런데 그 이미지 속 글자는 컴퓨터가 "글자"로 인식하지 못함.
- OCR은 그 이미지 속 글자를 분석해서 텍스트로 추출해줌.  <br/> ⇒ 그래서 편집하거나 검색하거나 복사할 수 있음


☑  **지식베이스(Knowledge Base)**
- 말 그대로 지식을 체계적으로 저장하고 관리하는 데이터베이스
- 사람이나 시스템이 문제를 해결하거나 의사결정을 할 때 참고할 수 있도록 사실, 규칙, 경험, 통찰 등을 모아둔 저장소라고 보면 됨.

📚 지식베이스란?
- 전문가 시스템이나 인공지능에서 사용되는 핵심 구성 요소 중 하나
- 특정 분야의 전문 지식, 문제 해결 방법, 규칙 등을 IF-THEN 형식이나 프레임 구조로 저장
- 사용자는 이 지식베이스를 통해 질문에 대한 답을 얻거나, 시스템은 이를 기반으로 추론을 수행할 수 있음

🧠 AI 지식베이스: 최근에는 AI 기반 지식베이스가 등장하면서 훨씬 더 똑똑해졌음
    | 구분 | 기존 지식베이스 | AI 지식베이스 | 
    |-----|---------------|--------------| 
    | 구조      | 정적인 문서 저장           | 동적으로 학습하고 업데이트 | 
    | 검색 방식  | 키워드 기반               | 의미와 맥락 기반 검색 (NLP) | 
    | 사용자 경험 | 모든 사용자에게 동일한 결과 | 개인화된 결과 제공 | 
    | 예시       | FAQ, 매뉴얼              | AI 챗봇, 자동 추천 시스템 | 


AI 지식베이스는 사용자의 질문을 이해하고, 관련 문서나 데이터를 연결해서 즉시 답변을 제공할 수 있어. 마치 제2의 뇌처럼 작동하는 거지
