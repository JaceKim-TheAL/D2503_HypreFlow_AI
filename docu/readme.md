### HyperFlow 특징
- 개발부터 서비스 런칭까지 하나의 플랫폼에서
- 구성은 자유롭게, 결과 확인은 실시간으로
- 드래그 앤 드롭으로 간편한 워크플로우 설계
- 고급노드 하나로 복잡한 로직을 간단하게
- 노코드로 설계하고 필요할 땐 풀코드로 맞춤 설정

| 특징 | 설명 |
|-----|-----|
| 개발부터 서비스 런칭까지 하나의 플랫폼에서     | 아이디어 구상부터 개발, 테스트, 실제 서비스 배포까지, 모든 과정을 한 플랫폼에서 빠르고 유연하게 진행할 수 있습니다. |
| 구성은 자유롭게, 결과 확인은 실시간으로       | LLM모델, 데이터, 프롬프트, 임베딩, 양자화 방식까지 핵심 요소를 자유롭게 조정하며 반복 테스트 할 수 있습니다. 실행 결과는 클릭 한 번으로 바로 확인 할 수 있어요. |
| 드래그 앤 드롭으로 간편한 워크플로우 설계     | 직관적인 UI로 노드를 연결해 원하는 흐름을 설계하고, AI 서비스를 쉽고 빠르게 완성할 수 있습니다. |
| 고급노드 하나로 복잡한 로직을 간단하게        | 반복 작업부터 조건 처리, 메모리 관리까지 손쉽게 구성하며 정밀한 AI 설계까지 가능합니다. |
| 노코드로 설계하고 필요할 땐 풀코드로 맞춤 설정 | 노코드로 시작하고, 필요할 땐 코드로 직접 기능을 확장하세요. 파이썬 노드를 활용하면 더욱 정교한 워크플로우 설계가 가능합니다. |
