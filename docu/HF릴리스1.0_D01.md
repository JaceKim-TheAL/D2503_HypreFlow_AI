# 1. 하이퍼플로우 v1.0 릴리스 노트
생성형 AI를 가장 쉽게 만들 수 있는 곳 - 하이퍼플로우에 오신 것을 환영합니다

### 누구나 시작할 수 있는 AI, 지금 시작해 보세요

HyperFlow는 누구나 손쉽게 `고도화된 생성형 AI 애플리케이션을 만들고, 배포하고, 운영`할 수 있도록 돕는 혁신적인 `노코드/로우코드 플랫폼`입니다.

개발 워크플로우를 빠르게 진행하고 싶은 숙련된 개발자부터, 코딩 경험 없이도 AI의 가능성을 활용하고 싶은 사용자까지 — HyperFlow는 아이디어를 실현하는 데 필요한 도구와 유연함을 모두 갖추고 있습니다.
<br/>

## 왜 하이퍼플로우여야 할까요?

빠르게 진화하는 AI 기술의 시대, HyperFlow는 **강력함과 접근성**을 동시에 갖춘 플랫폼입니다.

### 🔮 코딩을 모르는 비개발자도 쉽게 사용 할 수 있어요

- **비주얼 플로우 빌더**: 직관적인 시각적 에디터에서 기능 노드를 연결해 AI 애플리케이션을 만들어보세요
- **사전 구축된 템플릿**: 자주 사용되는 AI 활용 사례를 기반으로 바로 시작할 수 있습니다
- **코딩 필요 없음**: 단 한 줄의 코드 없이도 아이디어를 완성된 AI 앱으로 구현할 수 있습니다
- **가이드 기반 체험**: 인터랙티브 튜토리얼을 따라 몇 분 안에 첫 AI 애플리케이션을 만들 수 있습니다
<br/>

### 💻 개발자는 더욱 확장해서 사용할 수 있어요

- **개발 속도 향상**: 복잡한 AI 시스템을 몇 주가 아닌 몇 시간 만에 구축하세요
- **고급 기능 활용**: 사용자 정의 코드 노드, API 연동, 프로그래머블 워크플로우까지 자유롭게 다뤄보세요
- **간결하고 강력한 제어 API**: RESTful HTTP API로 플로우 실행, 제어, 상호작용이 가능합니다. 수많은 사용자 세션을 동시에 실행할 수도 있습니다
- **확장 가능한 아키텍처**: 원하는 대로 커스텀 노드, 서비스, 어댑터를 직접 만들어 활용하세요 (v1.0 릴리스 후 SDK 제공 예정)
<br/>

## 주요 기능

### ✨ 노드를 연결해 만드는 플로우 그래프 에디터

HyperFlow의 핵심은 **플로우 그래프 시스템** 입니다. 특화된 노드들을 시각적으로 연결해 AI 애플리케이션을 구성하는 강력한 비주얼 캔버스를 제공합니다. 각 노드는 데이터 처리부터 AI 모델과의 상호작용까지 다양한 기능을 수행합니다.

- **프로세스 흐름과 데이터 흐름의 통합 지원:** 다른 플랫폼과 달리, HyperFlow는 작업 순서를 제어하는 **프로세스 흐름**과 노드 간 정보를 전달하는 **데이터 흐름**을 하나의 그래프 안에서 모두 지원합니다.
- **다양한 노드 라이브러리:** LLM 통합, 지식베이스 관리, 콘텐츠 처리 등 다양한 목적에 맞는 50개 이상의 특화 노드를 사용할 수 있습니다.
- **실시간 테스트 환경:** 내장된 시뮬레이터를 통해 플로우를 즉시 테스트할 수 있습니다.
- **히스토리 추적 기능:** 이전 실행 기록을 확인하고, 애플리케이션을 반복적으로 개선할 수 있습니다.
<br/>

### 🧠 고급 AI 활용 기능

- **다양한 LLM 지원:** OpenAI, Anthropic, Google 등 주요 언어 모델을 자유롭게 연결할 수 있습니다.
- **지식베이스 구축:** 전용 RAG 노드를 활용해 벡터 데이터베이스를 생성, 관리, 질의할 수 있습니다.
- **멀티모달 처리:** 텍스트, 이미지, 오디오 등 다양한 데이터를 통합된 워크플로우 내에서 처리할 수 있습니다.
- **커스텀 프롬프트 엔지니어링:** HyperFlow의 자체 DSL과 템플릿 시스템을 사용해 프롬프트를 세밀하게 조정할 수 있습니다.
<br/>

### 🚀 기업용 비즈니스 수준의 확장성 제공

- **프로덕션 배포 지원:** AI 애플리케이션을 원클릭으로 손쉽게 배포할 수 있습니다.
- **API 연동 지원:** RESTful API를 통해 플로우를 제어하고 시스템에 유연하게 통합할 수 있습니다.
- **맞춤형 스타일링:** 기업 브랜드에 맞게 AI 애플리케이션의 UI를 자유롭게 커스터마이징할 수 있습니다.
- **사용 분석 기능:** 리소스 사용 현황을 추적하고, 성능 최적화를 위한 인사이트를 확보할 수 있습니다.
<br/>

### 하이퍼플로우 v1.0 릴리스 노트

생성형 AI 애플리케이션을 구축, 배포, 운영할 수 있는 통합 노코드/로우코드 플랫폼, **HyperFlow**의 공식 v1.0 출시를 기쁜 마음으로 안내드립니다. <br/>
150명 이상의 베타 테스터와 함께한 충분한 검증 과정을 거친 HyperFlow는 이제 프로덕션 환경에서도 안정적으로 사용할 수 있습니다.<br/> 
개발 경험이 많지 않아도, 모든 기술 수준의 팀이 손쉽게 고도화된 AI 애플리케이션을 만들 수 있습니다.

## 주요 기능

### HyperFlow IDE

- **비주얼 플로우 그래프 개발**    
    직관적인 드래그 앤 드롭 인터페이스로 노드를 연결해 강력한 AI 처리 플로우를 구성할 수 있습니다.
    
- **실시간 실행 엔진**    
    브라우저 내에서 플로우 그래프를 실행, 테스트, 디버깅할 수 있으며, 단일 스텝 실행 및 브레이크포인트 기능도 지원합니다.
    
- **50개 이상의 노드 라이브러리**    
    LLM 연동, 지식베이스 관리, 콘텐츠 처리, 플로우 제어, 데이터 변환 등을 위한 다양한 기능 노드를 제공합니다.
    
- **50개 이상의 서비스 통합 기능**    
    OpenAI, Anthropic, Google, Mistral 등 주요 AI 서비스와 손쉽게 연결할 수 있는 플러그 앤 플레이 방식의 통합을 지원합니다.
    
- **하이퍼파라미터 엔진**    
    23가지 파라미터 타입과 조건부 의존성 설정이 가능한 고급 파라미터 구성 시스템을 제공합니다.
    
- **에셋 브라우저 & 매니저**    
    모든 플로우 그래프 자산을 정리, 검색, 일괄 관리하고 사용 현황까지 추적할 수 있습니다.
    
- **프롬프트 인스트럭션 라이브러리**    
    프롬프트 템플릿을 시각적으로 작성, 저장, 재사용할 수 있어 LLM과의 상호작용을 최적화할 수 있습니다.
    

### 지식 관리

- **다양한 형식의 콘텐츠 가져오기**    
    PDF, 이미지, HTML, 텍스트 등 다양한 파일 형식을 지원합니다.
    
- **고급 세분화 기능**    
    콘텐츠를 의미 단위로 분할하고, 계층 구조를 자동으로 구성합니다.
    
- **벡터 데이터베이스 연동**    
    내장형 FAISS 벡터 스토어와 함께 Pinecone, ElasticSearch 등 외부 벡터 DB와의 연결을 지원합니다.
    
- **실시간 지식 주입 (Knowledge-injector)**    
    대화 도중에도 지식베이스를 실시간으로 업데이트할 수 있습니다.
    

### 애플리케이션 배포

- **프로덕션 플로우 그래프 엔진**    
    배포된 애플리케이션을 위한 성능 최적화 실행 환경을 제공합니다.
    
- **제어 API (Control API)**    
    플로우 그래프를 커스텀 애플리케이션에 통합할 수 있도록 하는 RESTful 엔드포인트를 제공합니다.
    
- **임베디드 챗봇**    
    다양한 스타일과 멀티모달 입력을 지원하며, 웹사이트에 삽입 가능한 챗봇을 WYSIWYG 에디터로 손쉽게 제작할 수 있습니다.
    
- **프로젝트 관리 기능**    
    플로우 그래프와 관련 자산을 팀 단위로 구성하고 협업할 수 있도록 지원합니다.
    

### 엔터프라이즈 기능

- **BYOK(Bring Your Own Keys)**    
    외부 서비스의 API 키를 직접 등록해 보안성 있게 사용할 수 있습니다.
    
- **멀티 테넌시 지원**    
    조직 및 프로젝트 단위의 접근 권한 제어를 제공합니다.
    
- **리소스 사용량 모니터링**    
    저장 공간, 연산 시간, API 호출량을 추적하고 할당량(quota)을 설정할 수 있습니다.
    
- **작업 복구 시스템**    
    시스템 업데이트 중 중단된 작업을 자동으로 복구합니다.
    

### 개발 도구

- **Python 실행 환경**    
    사용자 정의 데이터 변환을 위한 보안성 있는 Python 코드 실행 기능을 제공합니다.
    
- **Key-Value 저장소**    
    대화 중 상태 유지를 위한 영속적 저장소를 제공합니다.
    
- **복합 프롬프트 구성**    
    지시문, 히스토리, 지식 정보를 조합해 프롬프트를 세밀하게 구성할 수 있습니다.
    
- **구독 관리 기능**    
    사용량 할당량과 API 접근 제어가 적용된 다양한 요금제 플랜을 제공합니다.
